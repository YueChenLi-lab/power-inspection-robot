# 模块边界与依赖

| 模块 | 输入 / 输出 | 负责 | 不负责 |
|---|---|---|---|
| 原 voice_lab / ASR | 音频 → 原始转写及采样元数据 | 独立语音实验 | OS 调度、执行审批 |
| Brain v2/v3 | 文本 → 不可执行语义草案 | 术语、实体、关系和证据校验 | 现场事实核验、运动权限 |
| Ollama Provider | 有限文本与证据 → JSON 候选 | 原生 Schema 请求和失败诊断 | 硬件控制、自动下载/训练模型 |
| BrainAdapter | 语义结果 → 新的 Mock-only 任务 | 重新验证原文、意图、设备与时间；白名单映射 | 把模型声明当审批或真实设备身份 |
| OS core | 已验证请求 → 任务与事件 | 状态、注册、审批、排队与领取 | 具体业务、模型推理 |
| runtime | 已领取任务 → 输出或错误 | 子进程截止时间、取消、重试及恢复 | 驱动、任意不可信插件安全沙箱 |
| Mock Skills | 明确 Mock ID 和时间窗 → 模拟记录/建议 | 固定数据只读演示 | 现场异常判定或导航 |
| storage | 任务变化 → SQLite 事务 | 任务/事件/outbox 一致性、唯一幂等键 | 外部副作用 Exactly-once |
| observability | 实际事件与计时 → 分布/图表 | trace、指标、实验报告 | 给未接入阶段编造数值 |
| data_pipeline | 有来源的证据 → 校验存储与同步 | 背压、批写、SHA、保留边界 | 静默丢弃关键事件、默认删除审计 |

OS 核心不导入 Brain；只有可选适配层加载现有 Brain。从仓库根目录执行 `python3 -m InspectionOS`，无需 pip 安装。核心为标准库；Linux `fork` / `flock` 用于当前执行与互斥，未声明 Windows 原生支持。Xavier 部署也未验证。

`submit_result()` 不采信传入的“已校验”标志，会按原始文本和参考时间重建证据、调用原 Validator。输出中存在授权字段为 true 会拒绝。设备只映射到 `MOCK-CB-3` / `MOCK-TR-1`，不变成真实资产唯一 ID。不同业务 Skill 需要明确分解，本版本不会静默选择一部分执行。
